# 短线决策台四策略 (S1~S4) 推送优化设计方案

- **日期**：2026-09-17
- **状态**：已完成需求对齐与架构评审
- **目标**：在短线决策台推送体系中，深度整合 S1 竞价首板、S2 主线龙头主升、S3 涨停后回调低吸、S4 量价突破回踩四套战法，实现“独立规则判定 + Line 67 评分排序 + 全天时钟闭环 + 飞书分栏卡片 + 模拟账户策略分仓”。

## 一、 核心设计原则与架构边界

1. **策略独立定义，拒绝混淆**：
   四套策略（S1、S2、S3、S4）各自保留独立信号条件。每套策略均包含“首版/入选信号（WATCHING）”、“观察及确认（CONFIRMED）”和“失效条件（INVALIDATED）”。
2. **综合评分仅作为排序字段，不替代策略定义**：
   沿用 [Line 67 竞价及开盘承接打分口径](/Users/yang/Documents/股票/通达信/quant_system/docs/superpowers/specs/2026-09-13-short-term-decision-desk-design.md:67) 计算综合得分（TotalScore）。该评分**仅用于**同一策略内部多只候选标的的优先级排序（择优推送 TOP 1~2），绝不以分数代替战法规则，也不因分数高低剥夺符合战法标的的身份。
3. **消除未来数据与倒推**：
   - S1 今日最终是否首板只作收盘结果标签，不作为盘中入选条件；
   - S2 盘前/早盘固定“主线板块”和“龙头候选”，盘中 09:40/10:00 检查承接，避免收盘后倒推谁是龙头；
   - S3 记录首板低点、涨停实体中点和调整期量能，支撑区间与入选池由已完成日线盘前固定；
   - S4 平台边界（前高 Ceiling）严格使用突破前 20 日数据计算，突破日放量由历史均量比对确定。
4. **两级信号分离与全天时序闭环**：
   把“入选观察”和“确认转强”分开记录，构建 09:26（竞价初筛）➔ 09:38（开盘承接）➔ 10:00（早盘定势）➔ 14:30（尾盘决胜）➔ 15:30（复盘日结）全天闭环。

## 二、 四策略详细量化规则

### 1. S1 竞价首板 (`S1_AUCTION_FIRST_BOARD`)
> 依据《短线操盘笔记》竞价首板章节（短线操盘笔记160页.pdf）

- **首版信号（09:25 竞价入选，`WATCHING`）**：
  1. 竞价成交金额达到默认 500 万元（$\ge 5.0 \times 10^6$ 元）；
  2. 竞价涨幅落在优选黄金区间 $[+1.5\%, +6.5\%]$；
  3. **此前没有连续涨停身份**：昨日不是涨停板（`yesterday.is_limit_up == False`），历史无连板身份；
  4. **所属板块同步走强**：所属行业板块竞价均涨幅排名前列且上涨家数比例 (Breadth) $\ge 50\%$；
  5. 竞价量比 $VR \ge 1.4$。
- **观察及确认（09:32~09:38 开盘确认，`CONFIRMED`）**：
  1. 仍守住竞价价：现价 $\ge$ 竞价开盘价（红盘承接不破，$\text{price} \ge \text{open}$）；
  2. 成交活跃：累计成交额超竞价金额（$\text{amount} \ge \text{auction\_amount}$）；
  3. 记录“竞价入选”和“开盘确认”两级信号；今日最终是否首板只作盘后结果标签。
- **失效条件（`INVALIDATED`）**：
  1. ST、*ST 或退市风险；
  2. 竞价数据为估算却未标明；
  3. 开盘明显走弱：现价跌破竞价开盘价超过 $2.0\%$（即 $\text{price} < \text{open} \times 0.98$）或高开走弱幅度 $> 2.0\%$。

---

### 2. S2 主线龙头主升 (`S2_SECTOR_LEADER`)
> 依据《主升龙头空空1090》主线及龙头阶段描述（主升龙头空空1090 情绪周期 四万字.pdf）

- **首版信号（09:25~09:40 龙头候选，`WATCHING`）**：
  1. **主线板块锁定**：板块在涨幅、上涨家数（Breadth $\ge 50\%$）、涨停数和主力资金流入上进入全市场前 3 列；
  2. **龙头候选锁定**：个股处于板块前排涨幅领先位置，具备显著相对强度，且成交额 $\ge 3000$ 万元；
  3. 每日早盘固定“主线板块”和“龙头候选”判定，杜绝收盘倒推。
- **观察及确认（09:40 或 10:00 龙头定势，`CONFIRMED`）**：
  1. 板块持续位于前列，未出现板块退潮或资金断崖流出；
  2. 候选个股维持领涨前排地位，现价 $\ge$ 开盘价，且分时价格稳居 VWAP 均线之上。
- **失效条件（`INVALIDATED`）**：
  1. 板块退潮（跌出领涨前列、资金大额净流出）；
  2. 候选失去领涨地位、分时跌破均线走弱；
  3. 流动性不足。

---

### 3. S3 涨停后回调低吸 (`S3_LIMITUP_PULLBACK`)
> 依据《量价操盘笔记》涨停回调与洗盘体系（量价操盘笔记.pdf）

- **首版信号（盘前日线构建，`WATCHING`）**：
  1. 历史上出现自然首板（前 3~5 日出现首板，非一字板，首板日前一天非涨停）；
  2. 随后至少数日（2~4 日）缩量回调，记录关键边界：
     - **首板低点支撑**：$Low_{limitup}$；
     - **涨停实体中点**：$Midpoint = (Open_{limitup} + Close_{limitup}) / 2$；
     - **调整期量能**：调整期平均成交量严格小于首板日成交量。
- **观察及确认（14:30 尾盘或早盘转强，`CONFIRMED`）**：
  1. **变体 A（涨停回调低吸）**：价格靠近预先确定的支撑区 $[Low_{limitup}, Midpoint]$，且出现止跌（站稳当日开盘价）；
  2. **变体 B（首板洗盘后再启动）**：调整后放量上攻突破前一日高点重新转强；
  3. 信号分别记录“回调到位”和“确认转强”。
- **失效条件（`INVALIDATED`）**：
  1. 有效跌破首板低点（$\text{price} < Low_{limitup}$）；
  2. 调整量价不符合预设条件（调整期异常放巨量跌破）。

---

### 4. S4 量价突破回踩 (`S4_VOLUME_BREAKOUT`)
> 依据《Mistery趋势交易论2025》突破、回踩及多周期确认内容（Mistery趋势交易论2025.pdf）

- **首版信号（盘前日线构建，`WATCHING`）**：
  1. 日线放量突破此前已形成的平台或前高；
  2. **严格无未来数据**：平台边界 $Ceiling_{20}$ **必须用突破前的数据计算**（取突破日前 20 个交易日的最高价为平台顶）；
  3. 突破日成交量 $\ge 1.5 \times$ 平台 20 日平均成交量。
- **观察及确认（14:30 尾盘或分时站稳，`CONFIRMED`）**：
  1. **记录首次回踩**：突破后盘中出现回踩动作（分时最低价 $\le Ceiling_{20} \times 1.01$）；
  2. **回踩未破支撑且重新上行**：当前价格稳守在平台顶上方（$\text{price} \ge Ceiling_{20}$ 且 $\text{price} \ge \text{open}$，分时翻红向上发散）；
  3. 分别统计记录“直接突破”和“回踩确认”，避免混为一个结果。
- **失效条件（`INVALIDATED`）**：
  1. 跌回平台内（$\text{price} < Ceiling_{20} \times 0.98$）；
  2. 突破后量价背离或超过 3 个交易日仍无企稳确认。

## 三、 Line 67 量化评分模型（仅作排序字段）

沿用设计文档规范打分，分为竞价分（$AuctionScore$）与承接分（$ConfirmScore$）：

### 1. 竞价评分模型 ($AuctionScore$, 满分 100)
$$AuctionScore = \text{clamp}(S_{amount} + S_{price} + S_{vr} + S_{sector} + S_{cap} + S_{market}, 0, 100)$$
- **资金强度 $S_{amount}$ (0~24分)**：$\text{clamp}(\log_{10}(\text{amount}/10^4) \times 7 - 8, 0, 24)$
- **价格合理性 $S_{price}$ (0~18分)**：
  - 高开落在 $[+1.5\%, +6.5\%]$：**18分**
  - 高开落在 $(0\%, +1.5\%)$ 或 $(+6.5\%, +9.0\%)$：**10分**
  - 其余：**2分**
- **量比异动 $S_{vr}$ (0~15分)**：$\text{clamp}((VR - 1) \times 6 + 5, 0, 15)$
- **行业共振 $S_{sector}$ (0~20分)**：所属板块均涨幅 $\times 7 + \text{breadth} \times 20 + \text{strong} \times 2$
- **流通市值 $S_{cap}$ (0~10分)**：20~100 亿得 10 分，15~160 亿得 6 分
- **市场情绪修正 $S_{market}$ (±8分)**：进攻模式 +8 分，中性模式 +2 分，防守模式 -8 分

### 2. 开盘承接确认评分模型 ($ConfirmScore$, 满分 100)
$$ConfirmScore = \text{clamp}(S_{hold} + S_{trend} + S_{liq} + S_{sector} + S_{market}, 0, 100)$$
- **开盘承接度 $S_{hold}$ (0~22分)**：
  - $\text{price} \ge \text{open}$：**22分**
  - $-1.5\% \le \frac{\text{price} - \text{open}}{\text{open}} < 0\%$：**12分**
  - 其余：**0分**
- **冲拔斜率 $S_{trend}$ (0~20分)**：$\text{trend} = \text{当前涨跌幅} - \text{竞价涨幅}$
  - $\text{trend} \ge +0.3\%$：**20分**
  - $\text{trend} \ge -0.5\%$：**12分**
  - 其余：**2分**
- **流动性放量 $S_{liq}$ (0~18分)**：$\text{clamp}(\log_{10}(\text{成交额}/10^4) \times 8 - 12, 0, 18)$

### 3. 综合总分判定
- **09:30 前**：$TotalScore = AuctionScore$
- **09:30 后**：$TotalScore = AuctionScore \times 0.4 + ConfirmScore \times 0.6$
- **评级基准**：$\ge 80$ (S级)；$\ge 70$ (A级)；$\ge 60$ (B级)；$<60$ (C级)。

| 时点 | 触发阶段 | 执行操作 | 重点关注策略 | 输出信号 |

| **15:30 (前日)** | `review` | 自动扫描历史日线，计算并持久化观察池 | S3 / S4 | `s3_pullback_pool` 与 `s4_breakout_pool` |

## 五、 飞书卡片展示与 10万模拟账户执行

### 1. 飞书卡片分策略重构
- **卡片 Header**：根据时段与大盘姿态展示动态颜色（早盘竞价-橙色、开盘强攻-红色、早盘定势-紫色、尾盘低吸-蓝色）；
- **策略独立分栏**：
  - 🎯 **【S1 竞价首板 · 开盘确认】**
  - 👑 **【S2 主线龙头 · 定势确认】**
  - 🛡️ **【S3 涨停回调 · 低吸到位】** (附注变体：回调低吸 / 洗盘再启动)
  - ⚡ **【S4 量价突破 · 回踩企稳】** (附注：直接突破 / 回踩确认)
- **个股详细展示要素**：
  - 股票代码 + 名称 + 现价 (涨跌幅) + 评级与得分【如：S级 86.5分】；
  - 策略量化依据（如：竞价金额1280万、高开+3.5% / 首板支撑位 12.35元、调整缩量38%）；
  - **风控失效线**（明确标注策略失效观察位，如：跌破竞价价 ￥14.60 即失效）；
  - 模拟买入明细（买入股数、占用金额、仓位占比）。

### 2. 10万元模拟账户分时分仓规则
- **早盘时段 (09:26~10:00)**：配置 S1 竞价首板与 S2 主线龙头确认标的；
- **尾盘时段 (14:30)**：配置 S3 涨停回调低吸与 S4 量价突破回踩确认标的；
- **风控上限**：进攻模式上限 4 只（满仓）、中性模式上限 3 只（75%仓位）、防守模式上限 2 只（50%仓位）；
- **实盘原则**：严格排除涨停已封死标的（主板 $\ge 9.7\%$，双创 $\ge 19.5\%$）。
